## 🔑 START-HERE — the ones I was unsure about

### F (feedrate)
- **What it is:** How fast the toolhead (nozzle) moves. Units = mm/min.
- **Common wrong instinct:** "F = filament speed." NO. F is *motion* speed, not material speed.
- **Conversion:** Divide F by 60 to get mm/s. (F1500 = 25 mm/s. F3600 = 60 mm/s.)
- **Sticky:** Once written, F stays in effect for every following move until a new F is written. This is why the cube G-code was at 25 mm/s the whole file.

### E (extruder amount)
- **What it is:** How much material gets pushed out during a move.
- **Units:** Normally mm of filament. BUT — with `M229 E1 D1` (volumetric mode, which the Hyrel header turns on) E becomes **mm³** of ink. Big difference.
- **Mental model:** E = how much, F = how fast. Two different buckets.

### Slic3r vs. PrusaSlicer
- **Slic3r:** Original open-source slicer (MIT licensed). GitHub: slic3r/Slic3r.
- **PrusaSlicer:** A fork of Slic3r maintained by Prusa Research. **This is what Nick uses** (confirmed from G-code header: "generated by PrusaSlicer 2.9.2").
- Most settings have the same names in both. The Slic3r manual still works as a backup reference.
- **Repetrel:** Different thing. Hyrel's own program that runs the printer. Its built-in slicer integration is broken; that's why Nick uses standalone PrusaSlicer.

## 🧭 G-code commands — MOVEMENT

| Command | Plain-English |
|---|---|
| `G0` | Rapid (travel) move. No extrusion. |
| `G1` | Controlled move. May or may not extrude (depends on whether E is included). |
| `G28` | Home. Sends axes to the zero position. |
| `G92` | Set current position. Used to define Z-offset (e.g. `G92 Z0.1` says "treat this height as new zero"). |
| `G21` | Set units to millimeters. |
| `G90` | Absolute coordinates (X10 means "go to X=10"). |
| `G91` | Relative coordinates (X10 means "go 10 mm further in X"). |
| `G53` | Clear/cancel coordinate offsets. |

## 🌡️ G-code commands — TEMPERATURE & STARTUP

| Command | Plain-English |
|---|---|
| `M104 S[temp]` | Set extruder temp. **No wait** — continues to next command. |
| `M109 S[temp]` | Set extruder temp **and wait** until reached. |
| `M140 S[temp]` | Set bed temp, no wait. |
| `M190 S[temp]` | Set bed temp and wait. |
| `M82` | Absolute extrusion (E values are absolute totals). |
| `M83` | Relative extrusion (E values are deltas per move). |
| `M84` | Disable stepper motors. Usually at end of print. |
| `M106 C[val]` | Fan ON. C255 = 0–255 scale. |
| `M107` | Fan OFF. |
| `M5` | Spindle off (laser/spindle gear). |

## ⚙️ G-code commands — HYREL-SPECIFIC

| Command | Plain-English |
|---|---|
| `M229 E1 D1` | Enable **volumetric E-values** (E in mm³, not mm). Always in Hyrel's start G-code. |
| `M756 S[val]` | Set layer height. Hyrel calls this every layer change. |
| `M727 P[head]` | Prime head (push ink to the tip before printing starts). |
| `M729 P[head]` | Un-prime / retract head. |
| `M204 S[val]` | Set acceleration. |
| `M790` | Execute any new-layer actions. |
| `M772 S1` | Reset metrics + arm automatic reporting (housekeeping). |
| `M627` | Setup abort action — if something fails, this defines what happens. |
| `M620 T100 E0` | CO₂ lasers off. |
| `T0 / T1 / T12` | Select tool/head in slot 0, 1, or 12. Hyrel has multiple slots. |
| `M722 / M721` | Tool-change priming sequences (run during a swap between heads). |

## 📐 G-code parameters — INSIDE A LINE

A full move line looks like:
```
G1 X10.5 Y20.3 Z0.4 E5.2 F1500 ; description
```

| Letter | Meaning |
|---|---|
| `X` | X-axis position (mm, absolute by default). |
| `Y` | Y-axis position. |
| `Z` | Z-axis position (height). |
| `E` | Extruder amount. mm of filament — or **mm³** if M229 volumetric mode is on. |
| `F` | Feedrate (motion speed) in mm/min. Sticky. |
| `;` | Comment. Everything after is ignored by the printer. |

**Trick to know:** If a `G1` line has X/Y but NO E, it's a **travel move** (nozzle moves, nothing extruded). If it has X/Y **and** E, it's a **print move**.

## 🛠️ Slicer (PrusaSlicer / Slic3r) — KEY SETTINGS

### Speed settings
| Setting | What it controls |
|---|---|
| `travel_speed` | Feedrate when NOT extruding. Want this **higher** than print speed (3–10×) to reduce ooze during reposition. |
| `perimeter_speed` | Speed printing outer walls. |
| `external_perimeter_speed` | Speed printing the outermost visible wall (often slower for finish quality). |
| `infill_speed` | Speed for the fill pattern inside. |
| `first_layer_speed` | Speed for layer 1 only. Usually slower for adhesion. |
| `small_perimeter_speed` | Speed on tight curves / small radii. |
| `bridge_speed` | Speed when spanning a gap. |
| `max_print_speed` | Hard cap on any print speed. |

### Material flow
| Setting | What it controls |
|---|---|
| `extrusion_multiplier` | Scales the E values up/down. **0.95–1.05 is the normal tuning range.** Drop if over-extruding (blobs); raise if under-extruding (gaps). |
| `extrusion_width` | The width of the line the slicer expects each pass to lay down. |
| `first_layer_height` | Height of layer 1. Often equals layer_height; sometimes slightly larger for adhesion. |
| `layer_height` | Height of every layer after layer 1. |

### Retraction (anti-stringing)
| Setting | What it controls |
|---|---|
| `retract_length` | mm of filament/ink pulled back before a travel move. **Currently 0 in our config — likely the next thing to tune.** |
| `retract_speed` | How fast to retract. Faster = sharper "stop" of flow. |
| `retract_before_travel` | Minimum travel distance before retraction kicks in (so it doesn't retract every tiny hop). |
| `retract_lift` (Z-hop) | mm to lift the nozzle during travel so it doesn't drag across the print. |
| `wipe` | Tells the nozzle to wipe sideways while retracting, smearing the bead instead of leaving a blob. |

### Geometry / pattern
| Setting | What it controls |
|---|---|
| `perimeters` | Number of outer walls per layer. |
| `fill_density` | Infill percent (0%–100%). |
| `fill_pattern` | Rectilinear, honeycomb, gyroid, etc. |
| `top_solid_layers` / `bottom_solid_layers` | How many fully solid layers cap the part top and bottom. |
| `avoid_crossing_perimeters` | If true, travel paths route around walls instead of over them. Reduces stringing. |
| `only_retract_when_crossing_perimeters` | Retract only when a travel actually crosses a wall (not on every hop). |
| `skirts` / `brim_width` | Extra perimeter rings around the part (skirt = standalone; brim = touching the part) for first-layer priming/adhesion. |

## 🖨️ Hyrel SYSTEM 30M — HARDWARE

| Term | Meaning |
|---|---|

| **Repetrel** | Hyrel's proprietary control program. Runs on the lab ThinkPad. Sends G-code to the machine + lets you do mid-print tweaks. |

## 🧪 MATERIALS

| Term | Plain-English |
|---|---|
| **PCL (polycaprolactone)** | Biodegradable hydrophobic polyester. Melt temp ~60 °C. FDA-approved. Tissue scaffolds, drug delivery, soft robotics. Your primary material. |
| **PEO (polyethylene oxide)** | Water-soluble hydrophilic polymer. Blends with PCL (1:1) to add wettability and surface roughness. |
| **PEDOT:PSS** | Most common conducting polymer. Sold as a watery dispersion (Clevios PH1000). Yuk 2020 turned it into a printable paste. |
| **PANI (polyaniline)** | Another conducting polymer. Chemically simpler than PEDOT:PSS. Eventual target for our blend work. |
| **PDMS (polydimethylsiloxane)** | Silicone elastomer. Soft, biocompatible, insulating. Used as the "body" of soft electronics. |
| **DCM (dichloromethane)** | Volatile organic solvent. Dissolves PCL well. **Toxic — needs a fume hood.** |
| **ACE (acetone)** | Less toxic solvent. Also dissolves PCL, but inks based on it recover viscosity worse than DCM ones (per Zhang 2021). |
| **Laponite** | Nanosilicate thickener. Used in Teixeira 2026 to rescue grid printability of weak agarose inks. PCL-world analog = PEO. |

## 🌊 RHEOLOGY & PRINTABILITY

| Term | Plain-English |
|---|---|
| **Shear-thinning** | Ink gets runnier as you push it harder. **Required for extrusion printing.** |
| **Yield stress** | The minimum stress needed to make the ink start flowing. Below it, the ink acts like a soft solid. Too low → drips. Too high → clogs. |
| **Power-law index (n)** | Number between 0 and 1. Lower = more shear-thinning. n = 1 means Newtonian (water-like). n > 1 means shear-thickening (NOT good for printing). |
| **Consistency index (m)** | Companion to n. Measures the magnitude of viscosity at low shear. |
| **Recovery (%)** | After you remove shear stress, how much of the original viscosity comes back. **≥ 80 % in ~90 s** is the working rule (Zhang). |
| **Thixotropy** | Combined idea: shear-thins on demand AND recovers when you stop. The full description of a "good DIW ink." |
| **Storage modulus (G′)** | Elastic component of the ink's response. High G′ = behaves more solid. |
| **Loss modulus (G″)** | Viscous component. High G″ = behaves more liquid. The crossover where G′ = G″ marks the yield point. |
| **Filament fidelity** | Printed line width ÷ nozzle diameter. ~1.0 is clean. >1 = ink is spreading. <1 = under-flow. |
| **Pore printability (Pr)** | For square-pore grids: Pr = L² / (16A). Pr = 1 = perfect; <1 = under-gelation; >1 = over-gelation. |
| **Woodpile construct** | Alternating perpendicular layer pattern. Standard DIW test geometry. |

| **CV** | Cyclic Voltammetry. Measures charge storage, redox stability of an electrode. |

## ⚠️ MENTAL-MODEL TRAPS (common wrong instincts and the right one)

| You might think… | But actually… |
|---|---|
| F is filament speed. | F is **nozzle motion speed** in mm/min. E is the filament amount. |
| Every G-code line needs an F. | F is **sticky** — only written when speed changes. One F at the top can drive the whole file. |
| G0 vs G1 is travel vs print. | Loosely true, but PrusaSlicer often uses G1 for both. The actual difference is **whether E is present**: no E = travel, with E = print. |
| "Slic3r" means PrusaSlicer. | Slic3r is the parent project; PrusaSlicer is the fork Nick uses. The G-code header will say which one. |
| Repetrel is the slicer. | Repetrel is the **printer controller**. Slicing happens in PrusaSlicer first; Repetrel just runs the result. |
| Retraction = always good. | Retraction = pulling material back to stop ooze. Currently set to 0 in our config. Helpful for DIW with stringing, but too much causes blobs at restart. |
| PCL prints like ABS. | No. PCL melts at ~60 °C, ABS at ~240 °C. Currently the filament profile is set up for ABS — flag this. |
| Higher E = bigger line. | Higher E = more material pushed. Bigger line ALSO depends on speed (F). Same E at half the F gives a fatter line. |
| Two circles printing badly = retraction problem. | Could be retraction, **or** travel speed (which was our problem), **or** Z-hop, **or** "avoid crossing perimeters" setting. Diagnose by changing one thing at a time. |
| Adding more layers = same print, taller. | First-layer settings differ from subsequent layers. If layer 1 is wrong, every layer above it inherits the problem. |
| Volumetric (M229) means "vacuum." | Volumetric here means **E is measured in mm³ of material** instead of mm of filament length. The Hyrel always uses this. |

## 🎯 IF I FORGET EVERYTHING ELSE, REMEMBER THESE 5

1. **F = motion speed (mm/min). E = material amount. F is sticky.**
2. **DIW travel speed should be 3–10× print speed.** Print 2–15 mm/s → travel 30–80 mm/s.
3. **Nick uses PrusaSlicer, not Slic3r or Repetrel's slicer.** Repetrel is just the printer controller.
4. **Retraction is currently set to 0.** Adding 1–3 mm of retraction is probably the next stringing fix.
5. **The Hyrel uses volumetric E (mm³), not linear mm.** Don't compare E numbers to FDM-printer tutorials online — they assume linear mm.
