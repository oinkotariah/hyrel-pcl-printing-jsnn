# Research Notes — Index

Study and literature notes for the JSNN / IMPACT Lab project. Drop this whole folder into your repo under `docs/`. Read in the numbered order.

## Project context (read this first)
The project started by exploring **PCL for bone-tissue-engineering scaffolds**, then **pivoted to flexible electronics** — using **PCL as a flexible substrate** combined with a **conductor** (graphite filler, and/or polyaniline). The PCL *fundamentals* still apply; only the *application* changed (bone scaffold → flexible conductor). So where the older notes talk about bone/scaffolds, treat that as background — the live goal is a **flexible conductive composite**.

---

## Reading order

**01 — PCL Fundamentals (`01_PCL_fundamentals_review.md`)**
What PCL is and why it's used: synthesis, Tg (−60 °C), Tm (~60 °C), molecular weight ↔ crystallinity, solubility, degradation. *Note: the bone-composite framing here is now background; the key property for the new project is PCL's **flexibility**.*

**02 — Conducting Polymers & PANI Primer (`02_conducting_polymers_PANI_primer.md`)**
The science behind the pivot: how conjugation creates a delocalized "electron cloud," why doping is needed (the silicon analogy), and how polyaniline switches conductive with acid. *Read sections 3–4 if nothing else.*

**03 — Printing & Preparation (`03_printing_and_preparation.md`)**
How these materials get made/shaped: solvent casting vs. melt processing, the fabrication-method menu, and where extrusion/direct writing fits. Covers both reference papers' printing/prep portions.

**04 — Conductive Composite Gameplan (`04_conductive_composite_gameplan.md`)**
The actual experiment: PCL + graphite, 5 loadings (10–30%), the percolation threshold, dog-bone specimens, conductivity testing, and both routes (3D print vs. mould-cast if the printer's down). Ties everything above together.
