# Print Run Log — PCL / Hyrel 30M

**How to use this (the whole trick):**
1. **One row per print attempt.** Even failed ones — *especially* failed ones.
2. **Change ONE thing per run** when you can. The "What I changed" column is the experiment.
3. **Always fill "Result" and snap a photo.** Name the photo `runNN_date.jpg` and put the name in the Photo column. A photo with no log entry is useless; a log entry with no photo is half-useless.
4. At the end of the day, the rows you marked **KEEP** are your poster's Results section.

If you only ever fill three columns, make them: **What I changed · What happened · Keep/Toss.**

## Things to capture once (not every run)

- **Nozzle gauge** — currently unknown. Measure the inner diameter or read the hub. This is run-blocking; do it first.
- **Material identity** — exact PCL Mw, and what (if anything) is mixed in (CaCO₃ / ground bone / HAp, and %).
- **What "pulse time" actually controls on this head** — ask Nick, write the answer here so you stop guessing:
  > _pulse time = ______________________________ (units: ____, raise it when: ____)_
- **Repetrel screenshot** of the working parameter set once you get a clean print — that's your "Printing Parameters" poster panel.

## Day-end habit (2 minutes)
Pick the single best print of the day, photograph it next to a ruler/scale, and write one sentence: *"Changing X from ___ to ___ did ___."* That sentence is a poster bullet.
